# Limits of Genuine Multipartite Steering with Incompatible Measurements

Computational companion to the theoretical study. This package contains only the source scripts and instructions needed to regenerate the computational outputs and vector figures. No experimental data were generated. The rank and stabilizer tests are sufficient certificates; their failure does not prove absence of GMS. The generator-sum numerical search gives feasible lower bounds, not a rigorous upper bound.

## Setup

Run commands in the root of this directory. Python 3.13 and a C++17 compiler (GCC or compatible, with GNU bit built-ins) are suitable. The requirements file records the Python package versions available during packaging; numerical last digits and PDF typography can vary across platforms. For the standalone TikZ circuit, install a LaTeX distribution with TikZ and pdfLaTeX.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Reproduce the results and figures

Run `bash reproduce.sh` from the repository root after installing the dependencies above. The script runs the following steps in dependency order:

```sh
python graph_checks.py
g++ -O3 -std=c++17 random_checks.cpp -o random_checks
./random_checks
g++ -O3 -std=c++17 all_pair_checks.cpp -o all_pair_checks
./all_pair_checks
python sparse_checks.py
python verify_paulis.py
OPENBLAS_NUM_THREADS=1 python benchmark_generator.py
python noise_budget.py
python make_figures.py
(cd figures && pdflatex -interaction=nonstopmode protocol.tex)
```

The CSV tables are generated locally; they are not tracked in this repository. The exact all-pair enumerations are computationally expensive. The plotting script requires the CSV files generated by the C++ programs. The analytical and numerical vector figures are written to `figures/`, and the preparation circuit is generated from `figures/protocol.tex`.

| Script | Output and manuscript connection | Sampling / seed |
|---|---|---|
| `graph_checks.py` | `atlas_results.csv`, `atlas_summary.csv`; Appendix G graph-atlas census | Exhaustive connected nonisomorphic graphs, 3–7 vertices |
| `random_checks.cpp` | `random_graphs.csv`, `random_summary.csv`; finite-size rank certificate figure | MT19937-64, 20261127; 100 samples per size 6–20; all pairs for 100 samples per size 6–14, 20 per size 15–16 |
| `all_pair_checks.cpp` | `all_pair_extension.csv`; extended all-pair figure | MT19937-64, 20261128; 20 samples per size 17–20, 10 per size 21–24; self-test on 140 graphs with seed 203 |
| `sparse_checks.py` | `sparse_checks.csv`; reduced trusted-check table | Python Random, 20261127; up to 3000 candidate subsets per size, first rank-certified graph at each size |
| `verify_paulis.py` | Terminal output; Pauli identities, rational obstruction and local noise threshold checks | Deterministic |
| `benchmark_generator.py` | `generator_benchmark.csv`; feasible generator-sum strategies | NumPy RNG, 20261127; 12 starts, at most 80 iterations, 15 cuts |
| `noise_budget.py` | `noise_budget.csv`; finite-shot table and gate/readout curves | Analytical model, deterministic |
| `make_figures.py` | All analytical and numerical vector plots | Dense graph illustration only: NumPy RNG, 15 |

Adjacency masks are decimal bit masks with bit `j` indicating an edge to vertex `j`. In `random_graphs.csv`, an all-pair flag of `-1` indicates that the all-pair test was not performed. The sparse-check generator labels are binary stabilizer-generator masks encoded in decimal.
