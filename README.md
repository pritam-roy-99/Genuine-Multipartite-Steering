# Fundamental Limits and Robust Certification of Genuine Multipartite Steering

Computational companion to the theoretical study. This package contains only the source scripts and instructions needed to regenerate the computational outputs and vector figures. No experimental data were generated. The rank and stabilizer tests are sufficient certificates; their failure does not prove absence of GMS. The generator-sum numerical search gives feasible lower bounds; the manuscript independently proves the exact biseparable maximum 2 + sqrt(5). The new visibility witness establishes the exact white-noise transition v = 1/(3 − sqrt(2)) for sharp X,Y measurements on the adjacent untrusted vertices of C5.

## Setup

Run commands in the root of this directory. Python 3.13 and a C++17 compiler (GCC or compatible, with GNU bit built-ins) are suitable. The requirements file records the Python package versions available during packaging; numerical last digits and PDF typography can vary across platforms. For the standalone TikZ circuit, install a LaTeX distribution with TikZ and pdfLaTeX.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Work interactively in Jupyter

Launch `jupyter lab` in the repository root. Open a notebook and run its cells in order with the Python 3 kernel. The notebooks are committed without cell outputs; generated data and figures remain local. The two C++ programs are retained for efficient exact rank tests and must be run before the reduced-check and figure notebooks.

## Reproduce the results and figures

Run `bash reproduce.sh` from the repository root after installing the dependencies above. The script runs the notebooks and compiled programs in dependency order.

```sh
bash reproduce.sh
```

The script executes notebooks in fresh kernels with `jupyter nbconvert`, keeping the source notebooks free of execution outputs. The order is graph census, the two C++ rank tests, reduced checks, Pauli verification, exact visibility and comparator checks, generator benchmark, noise budgets and figure generation, followed by compilation of the standalone TikZ circuit. For individual notebooks, use JupyterLab or the same `nbconvert --to notebook --execute` command (write the executed notebook to a separate output directory).

The CSV tables are generated locally; they are not tracked in this repository. The exact all-pair enumerations are computationally expensive. The plotting notebook requires the CSV files generated by the C++ programs. The analytical and numerical vector figures are written to `figures/`, and the preparation circuit is generated from `figures/protocol.tex`.

## Numerical checks for the revised manuscript

The notebooks use the same graph labels and random seeds as the manuscript. In particular, `verify_exact.ipynb` verifies the full conditional-operator decomposition at the exact critical visibility, the generator parity-block polynomial, the local-noise threshold and the trusted-measurement error coefficient. The optional dense-graph calculation uses the graph identified by the reduced-check output.

`noise_budget.ipynb` checks the four witness scores (generator, penalty, projected, visibility), the two reported finite-shot budget rows and the four gate-error endpoints at 1% readout error. The exact global white-noise transition is restricted to the five-cycle with the prescribed sharp measurement frame; the local and gate/readout error thresholds are model-conditional. The shot budgets are sufficient worst-case estimates.

Adjacency masks are decimal bit masks with bit `j` indicating an edge to vertex `j`. In `random_graphs.csv`, an all-pair flag of `-1` indicates that the all-pair test was not performed. The sparse-check generator labels are binary stabilizer-generator masks encoded in decimal.
