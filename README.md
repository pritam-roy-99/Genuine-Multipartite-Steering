# Fundamental Limits and Robust Certification of Genuine Multipartite Steering

Computational companion to the theoretical study. This package contains only the source scripts and instructions needed to regenerate the computational outputs and vector figures. No experimental data were generated. The rank and stabilizer tests are sufficient certificates; their failure does not prove absence of GMS. The generator-sum numerical search gives feasible lower bounds, not a rigorous upper bound.

## Setup

Run commands in the root of this directory. Python 3.13 and a C++17 compiler (GCC or compatible, with GNU bit built-ins) are suitable. The requirements file records the Python package versions available during packaging; numerical last digits and PDF typography can vary across platforms. For the standalone TikZ circuit, install a LaTeX distribution with TikZ and pdfLaTeX.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Work interactively in Jupyter

Launch `jupyter lab` in the repository root. Open a notebook and run its cells in order with the Python 3 kernel. The notebooks are committed without cell outputs; generated data and figures remain local. The two C++ programs are retained for efficient exact rank tests and must be run before the reduced-check and figure notebooks.

## Reproduce the results and figures

Run `bash reproduce.sh` from the repository root after installing the dependencies above. The script runs the notebooks and compiled programs in dependency order.

Run the entire sequence with:

```sh
bash reproduce.sh
```

The script executes notebooks in fresh kernels with `jupyter nbconvert`, keeping the source notebooks free of execution outputs. The order is graph census, the two C++ rank tests, reduced checks, Pauli verification, generator benchmark, noise budgets and figure generation, followed by compilation of the standalone TikZ circuit. For individual notebooks, use JupyterLab or the same `nbconvert --to notebook --execute` command (write the executed notebook to a separate output directory).

The CSV tables are generated locally; they are not tracked in this repository. The exact all-pair enumerations are computationally expensive. The plotting notebook requires the CSV files generated by the C++ programs. The analytical and numerical vector figures are written to `figures/`, and the preparation circuit is generated from `figures/protocol.tex`.

| Notebook or source | Output and manuscript connection | Sampling / seed |
|---|---|---|
| `graph_checks.ipynb` | `atlas_results.csv`, `atlas_summary.csv`; Appendix G graph-atlas census | Exhaustive connected nonisomorphic graphs, 3–7 vertices |
| `random_checks.cpp` | `random_graphs.csv`, `random_summary.csv`; finite-size rank certificate figure | MT19937-64, 20261127; 100 samples per size 6–20; all pairs for 100 samples per size 6–14, 20 per size 15–16 |
| `all_pair_checks.cpp` | `all_pair_extension.csv`; extended all-pair figure | MT19937-64, 20261128; 20 samples per size 17–20, 10 per size 21–24; self-test on 140 graphs with seed 203 |
| `sparse_checks.ipynb` | `sparse_checks.csv`; reduced trusted-check table | Python Random, 20261127; up to 3000 candidate subsets per size, first rank-certified graph at each size |
| `verify_paulis.ipynb` | Terminal output; Pauli identities, rational obstruction and local noise threshold checks | Deterministic |
| `benchmark_generator.ipynb` | `generator_benchmark.csv`; feasible generator-sum strategies | NumPy RNG, 20261127; 12 starts, at most 80 iterations, 15 cuts |
| `noise_budget.ipynb` | `noise_budget.csv`; finite-shot table and gate/readout curves | Analytical model, deterministic |
| `make_figures.ipynb` | All analytical and numerical vector plots | Dense graph illustration only: NumPy RNG, 15 |

Adjacency masks are decimal bit masks with bit `j` indicating an edge to vertex `j`. In `random_graphs.csv`, an all-pair flag of `-1` indicates that the all-pair test was not performed. The sparse-check generator labels are binary stabilizer-generator masks encoded in decimal.
